# MAGIC-ADVENTURE V.0.1
- MAGIC-ADVENTURE is a 2D platformer game with 3 levels. Complete all the objectives to win each level!
- The primary challenge is to attack the enemies with punch to kill them and collect all the coins.
# IMPORTANT NOTE
- This is the first version of the game, it has some incomplete sections (e.g., levels), however there is still only 2 levels left.
## How To Run The Game?
- To run the game you should open the itch.io link, then click the button "Run Game". So simple.
## How To Play The Game?
- To play the game correctly, you should click the "START" button in the main menu after running the game. Then select the one of the 3 levels.
- The only way to complete the level is by reaching the endpoint of each level. Also, it is optional to collect fruits, there is no required amount.
- You must avoid the fire. And if it damaged you 4 times in the same level, you will die.
  
## Controllers
- Movement is controlled using A and D or the ← and → arrow keys to move the character horizontally across the level.
- The player can jump using the spacebar or W button, you can also double click it if you want to double jump.
- Using ESC for pause.
