# MAGIC-Adventure V.0.1
- MAGIC-Adventure is a 2D platformer game with 3 levels. Complete all the objectives to win each level!
- The primary challenge is to attack the enemies with punch to kill them and collect all the coins.
# IMPORTANT NOTE
- This is the first version of the game, it has some incomplete sections (e.g., levels), however there is still only 1 or 2 levels left.
## How To Run The Game?
- To run the game you should open the itch.io link, then click the button "Run Game". So simple.
## How To Play The Game?
- To play the game correctly, you should click the "PLAY" button in the main menu after running the game. Then select the one of the 3 levels.
- The only way to complete the level is by defeating all the enemies with punch, and collecting all the coins.
- All the attacks have same damage effect on the enemies.
- You must prevent them from successfully attacking you, or you will lose.
- Each of enemies in every level needs two successful attacks to kill them.
  
## Controllers
- Movement is controlled using A and D or the ← and → arrow keys to move the character horizontally across the level and you can hold shift to run.
- The player can jump using the spacebar or W button.
- You can attack using the LMB or the E button for the attack.
- Using ESC for pause.
